# MotorLog 🚗⚙️

## Descripción del Proyecto
MotorLog es una aplicación web diseñada para que los propietarios de vehículos puedan llevar un control exhaustivo del mantenimiento y las modificaciones de sus coches. El objetivo principal es centralizar el historial mecánico para prevenir averías por falta de mantenimiento y llevar un control de las intervenciones y gastos asociados a cada vehículo.

Este repositorio contiene el código correspondiente al desarrollo del **Proyecto 1**.

## Tecnologías Utilizadas
* **Lenguaje:** Java 25
* **Framework Backend:** Spring Boot
* **Base de Datos:** MySQL
* **Persistencia:** Spring Data JPA / Hibernate
* **Frontend:** HTML, CSS básico y Thymeleaf
* **Entorno de Desarrollo:** Visual Studio Code
